# No Android o Nova reinicia o zygote e nunca o ril-daemon

Depois de gravar as propriedades do perfil, o Nova reinicia só o `zygote` (`setprop ctl.restart zygote`) em vez de reiniciar o aparelho: o kernel, o ADB e os eventos de toque continuam vivos, a conexão do Scrcpy sobrevive e o framework Java sobe limpo. Ele consulta `init.svc.zygote` por até 20 segundos e espera mais 2 s pelo serviço de entrada, porque voltar cedo demais fazia o Scrcpy perder o mouse. A espera é feita em linha (`await`), sem `setTimeout`, para o Scrcpy ter tempo de se recuperar. O `ril-daemon` nunca é reiniciado: isso deixa o IMEI em branco; o aviso de telefonia é um `Intent` seguro que faz o `TelephonyManager` reler as propriedades. O reboot completo só serve para voltar às propriedades originais da imagem de boot.
