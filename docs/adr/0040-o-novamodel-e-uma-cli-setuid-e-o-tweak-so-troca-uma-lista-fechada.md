# O `novamodel` é uma CLI setuid e o tweak só troca uma lista fechada de chaves

O spoofing de modelo do iPhone tem duas peças. O tweak `com.aquiles.novamodel` lê `/var/tmp/nova-model-control.json` (`{ "enabled", "productType", "name" }`, o mesmo padrão do OBSGraphBridge; `enabled: false` ou arquivo ausente é o modelo real) e só sobrescreve uma lista fechada de chaves de modelo do MobileGestalt, nunca serial, IMEI nem baseband. Ele guarda o arquivo em cache por `mtime` e tamanho, para a troca valer na chamada seguinte sem reler o JSON a cada `MGCopyAnswer` ou `sysctl`. A CLI `novamodel` (`set`, `clear`, `status`) grava o arquivo de controle.

A CLI é setuid root (instalada pelo `postinst`) porque o app a chama por SSH como `mobile` e ela precisa gravar em `/var/tmp`; é o mesmo mecanismo do `novaproxy`, que também é setuid e é a superfície de risco do conjunto. O `novalanguage`, ao contrário, é `755 root:wheel` e nunca setuid: ele só escreve as preferências do próprio `mobile`, e foi medido que isso não precisa de root. A CLI roda sem o tweak (o construtor do tweak ignora esse processo), por isso o `status` sempre devolve o `ProductType` verdadeiro como `real`. A remoção do pacote restaura o modelo real apagando o arquivo de controle.
